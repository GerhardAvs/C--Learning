# Programación Orientada a Objetos

Este repositorio contiene los ejercicios realizados para practicar conceptos básicos de programación y programación orientada a objetos en C++.

## 🎯 Propósito

El objetivo de esta actividad es llevar a la práctica los conceptos vistos en clase mediante ejercicios cortos que permitan escribir, ejecutar, depurar y documentar código.

Cada ejercicio incluye su código fuente y sirve como práctica para mejorar la lógica de programación y el uso de C++.

## 📋 Ejercicios

### 1. Calculadora de consola

Programa que recibe dos números y un operador (`+`, `-`, `*`, `/`) y muestra el resultado.

También valida la división entre cero.

### 2. Clasificador de calificaciones

Programa que recibe una calificación del 0 al 100 y determina su clasificación utilizando sentencias de control como `if/else`.

Las clasificaciones utilizadas son:

* NA
* S
* B
* MB
* E

### 3. Procesador de cadenas

Programa que recibe una frase y muestra:

* Número de palabras.
* Número de vocales.
* Frase invertida.

Para esto se utilizan funciones y herramientas para el manejo de cadenas.

### 4. Clase `Estudiante`

Se crea una clase `Estudiante` con los siguientes atributos:

* Nombre.
* Matrícula.
* Promedio.

La clase también contiene métodos para mostrar la información del estudiante y comprobar su situación académica.

### 5. Interacción entre objetos

Se crea una clase `Grupo` que utiliza un arreglo de objetos `Estudiante`.

El programa trabaja con un mínimo de tres estudiantes y calcula el promedio general del grupo.
